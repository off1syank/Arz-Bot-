Этот бот работает на Api Arz Market , присылает уведомления о предметах, выставленных ниже рынка.
Инструкция по использованию 

1)Скачать Python 3.14(проставьте галочки в установщике)

2)создать отдельную папку и распаковать туда файлы 

3)далее заходи в телеграмм в @BotFather, создавайте своего бота(туторы есть) после создания бота напишите ему что-нибудь в лс, чтобы он мог вам писать

4)также зайти в @idbotyra_bot и узнать свой chatid

5)потом открыть bot.py через блокнот и вписать 
BOT_TOKEN = "твой"
CHAT_ID = "твой"

6)открыть cmd и вставить "pip install requests", нажать enter и подождать завершения установки

6)запустить start.bat

7)заработать миллиарды долларов евро сша


Версию Python указал ту, на которой все точно работает, а так можете попробовать запустить на другой.

Кавычки обязательны в bot_token = "" и в chat_id = ""

Если не приходят уведомления, можно посмотреть файл bot.log, в котором пишутся все ошибки(если они есть), обычно помогает любой рабочий впн

Файл items data берется просто из moonloader в папке arzmarket, это нужно делать чтобы был актуальный список товаров(нужно менять, когда добавляют новые предметы)

Ускорить бота можно, но минимально, так как есть ограничения api, на него товар попадает через ~3 минуты после выставления его в игре, это ботом никак не ускорить
